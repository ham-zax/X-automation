01 / The decision

A reason to speak.
And a reason not to.

ACT

Join with something to add.

An explanation, a question, a useful reaction, or support. Not every good reply needs a miniature essay.

RESEARCH

Look closer before writing.

Read the source and conversation context. Uncertainty is a reason to investigate, not invent an anecdote.

SILENT

Skip the weak opportunity.

No meaningful contribution? Move on. Volume is a diagnostic, not the reason to interrupt someone.

04 / Execution, not guesswork

Before the click, a claim.
After the click, evidence.

An agent does not get to post just because it wrote something plausible. A live owner-granted delegation and objective send gates determine whether an action is allowed. Every attempt needs an outcome record.

  1. 01 / READ

    Scout

    Rank candidate conversations. No public write.

  2. 02 / THINK

    Write

    Propose a specific reply, quote or original.

  3. 03 / GATE

    Check

    Reject duplicates, near-copies, placeholders and bad format; request a rewrite when attribution needs work.

  4. 04 / GATE

    Claim

    Atomically reserve the action after checking health, timing and live authority.

  5. 05 / ACT

    Send

    Log the send-start, act once, then seek confirmation.

  6. 06 / LEARN

    Measure

    Reconcile the result and observe subsequent outcomes.

No proof of a send? The outcome stays unresolved, not magically "failed." It cannot be retried blindly.

This is a simplified map, not a live transaction. Read the actual Growth Run protocol ↗

Timing

Make room between posts.

Approximately 90 minutes between originals and 30 minutes between main-feed posts. Replies follow their own rules.

Originality

Add, don’t echo.

Repeated targets and near-copies are fenced. Referencing a source should add something of your own.

Clarity

Write for a human reader.

A clear useful sentence beats a dense paragraph full of performed expertise.

Control

No silent autopilot.

The continuous Node posting loop is disabled. Live browser actions belong to an attached, authorized operator.

Authority

Permission is not implied.

Delegation is granted by the owner, checked at claim time and can be revoked.

Ownership

One live operator.

A single operator lease avoids competing agents acting on the same account.

05 / Evidence over vibes

An outcome is not an explanation.

Cadence stores observation windows and experiment evidence so decisions can improve. A follower delta beside a post is correlation, not proof that the post caused it.

07 / The fine print

What it is.
What it isn’t.

Is this an open-source product?

The repository is source-available, but it currently does not include a project-level software license. Read and evaluate the implementation; check reuse permissions with the owner before distributing or adapting it.

Does it post on its own?

Not by default. The continuous background X browser loop is disabled. A live Growth Run uses an attached reasoning agent under an explicit owner delegation; the separate background API path has its own transport and authorization limits.

Is the mood just fake emotion?

No. Daily tone is a low-priority preference for word choice, not a statement about the owner's real feelings. The lab above is a static illustration. First-person factual experience still needs a basis.

Will it grow my account?

There is no guaranteed growth here, and no benchmark is claimed. The objective is relevant followers and durable relationships; the project measures observations without inventing causal credit for individual posts.

Whose voice does it write in?

The bundled persona models @ham_zax. It is transparent and versioned, but it is not magically your voice. Adapting it means supplying your own identity, evidence, preferences and boundaries.

What do I need to run it?

Node.js 24, local configuration, an AI provider, and the relevant X credentials or authenticated browser session. Publication capabilities differ by route; start with the repository setup and transport documentation.
