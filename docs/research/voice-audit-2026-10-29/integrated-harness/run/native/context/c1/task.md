Your phone can be where you fix the bug — not just where you read the issue.

AndroidHarness is a native Android AI coding-agent app for builders who want to work on real code projects directly from an Android device.

It helps you make and inspect changes without a PC or root by combining file tools, a Linux toolchain, GitHub workflows, and browser control inside a chat interface.

Key features:

• On-device project work – reads and edits files, runs shell commands, and supports git from the phone
• Inspectable agent actions – every tool call has a card, with diff sheets and recorded check outcomes available in chat
• GitHub workflows – import repositories, commit selected files, push changes, and verify the resulting remote commit
• Browser and preview tools – inspect web links or workspace previews, then navigate, snapshot, click, type, and capture screenshots
• Recovery for longer tasks – a foreground service, resume cards, and a persistent message queue help work continue through interruptions

It’s open-source (MIT license).
