# Peer-reply experiment handoff

These files preserve experiments on fictional posts. The prompts are candidates for evaluation. They do not change the production Writer contract or grant permission to publish.

- [Two-candidate prompt](two-candidate-prompt.md): exact GLM prompt body, reusable with new source context.
- [GLM checkpoint](glm-checkpoint.md): six prompt variations, source posts, prompts, and full outputs for GLM-5.3-Flash Free.
- [DeepSeek checkpoint](deepseek-checkpoint.md): later experiments, fictional source posts, outputs, reviewer evidence, and limitations.
- [DeepSeek two-candidate test](deepseek-two-candidate.md): exact DeepSeek prompt, fictional sources, and full output. This prompt differs from the GLM prompt.
- [DeepSeek initial test](deepseek-initial.md): original six-writer test and the first rule-based revision.

The two-candidate GLM sample looked promising in one subjective review. The models did not receive identical prompts, and the experiments do not establish a winner or latency difference. Both sometimes invented details or missed errors in self-review. Use fresh posts and the same prompt when comparing models. A visible check is not proof the check is correct.

These records contain examples and draft replies, not confirmed X actions. For live X work, follow the repository's authority and publication rules.
